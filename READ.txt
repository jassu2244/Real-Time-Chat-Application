Project Mental Model
This app has 3 flows:

Auth flow
Register/Login -> JWT cookie set -> later requests resolve current user

Public chat flow
Frontend STOMP publish -> backend message mapping -> DB save -> broadcast on topic -> all clients append message

Private chat flow
Frontend publish private message -> backend validates users -> DB save -> send to /user/{username}/queue/private for sender and receiver
